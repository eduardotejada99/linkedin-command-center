## 🔬 Detalle de los Módulos de Vanguardia

### 1. La Capa Semántica para IA (Semantic Layer & dbt)
* Las empresas no quieren que un LLM consulte una base cruda (alucina nombres de tablas y columnas).
* **Tu diferencial:** Construir la capa semántica intermedia con **dbt Semantic Layer / MetricFlow / Cube.js**. El LLM consulta métricas predefinidas (`ingresos_netos`, `ocupacion_camas`), garantizando **cero alucinaciones matemáticas**.

### 2. Agentes de Datos & Servidores MCP (Model Context Protocol)
* **MCP de Anthropic/OpenAI:** Es el nuevo estándar para conectar LLMs con herramientas empresariales.
* Desarrollar servidores MCP en Python que expongan bases de datos SQL (SQL Server, Postgres) de forma segura para que clientes como Claude, Antigravity o ChatGPT consulten datos corporativos con control de acceso.

### 3. Evals de IA (El Secreto de los Salarios Altos)
* Cualquier persona puede armar un prototipo de RAG en 20 minutos; casi nadie sabe evaluar si funciona en producción.
* Aprenderás a implementar métricas formales:
  * *Faithfulness*: ¿La respuesta está respaldada por los datos recuperados?
  * *Answer Relevance*: ¿El agente respondió exactamente lo que el usuario preguntó?
  * *Context Precision*: ¿La consulta SQL generada trajo solo lo necesario?
