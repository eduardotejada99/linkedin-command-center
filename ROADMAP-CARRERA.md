## 🏗️ EJE 1: Línea de Preparación Técnica (Upskilling de Alto Valor)

El mercado actual castiga el rol de "hacer dashboards básicos en Power BI" y premia a quien domina la ingeniería de transformación, la calidad de datos y el machine learning aplicado.

```
Fase 1: Modern Data Stack (Semanas 1-6)
├── SQL Avanzado (Window functions, CTEs recursivas, Query Optimization)
├── Modelado Dimensional Kimball (Star Schema, Fact/Dim tables)
├── dbt (data build tool) — Transformación versionada y tests
└── Cloud Data Warehouses (Snowflake / BigQuery / Azure Synapse)

Fase 2: Applied AI & Machine Learning de Negocio (Semanas 7-14)
├── Modelos Predictivos Clásicos (XGBoost, LightGBM para Churn y Forecasting)
├── Evaluación con Métricas de Negocio (ROC-AUC, Precision-Recall, Cost Matrix)
├── LLM Orchestration & RAG (Text-to-SQL analítico con LangChain/LlamaIndex)
└── MLOps Básico (Dockerización, despliegue de APIs de inferencia en FastAPI)

Fase 3: Proof of Work / Portafolio Irrefutable (Semanas 15-18)
├── Proyecto 1: Pipeline completo de Analytics Engineering con dbt + Postgres + Power BI
└── Proyecto 2: Asistente Text-to-SQL / Modelo Predictivo desplegado en la nube
```

### Detalle por Módulos:

### 1. SQL Avanzado & Optimización de Consultas
* Dominar `ROW_NUMBER()`, `RANK()`, `LEAD()`, `LAG()`, funciones de ventana acumulativas y marcos de partición.
* Análisis de planes de ejecución (`EXPLAIN ANALYZE` en Postgres, `SET STATISTICS PROFILE` en SQL Server).
* Creación de índices clustered vs non-clustered, índices cubrientes y particionamiento horizontal.

### 2. Analytics Engineering con dbt (data build tool)
* Creación de modelos staging, intermediate y marts.
* Implementación de tests de integridad referencial (`unique`, `not_null`, tests personalizados).
* Generación automática de linaje de datos (DAG) y documentación de catálogos de datos.

### 3. Machine Learning Aplicado a Negocio (Conexión con Maestría UNIR)
* En lugar de algoritmos abstractos, enfocarse en los 3 problemas universales de las empresas:
  1. **Forecasting / Demanda:** Predecir ocupación sanitaria o consumo de repuestos en maquinaria.
  2. **Clasificación / Churn:** Predecir abandono de clientes o pacientes en tratamiento.
  3. **Segmentación:** Clustering RFM / K-means para análisis de patrones de comportamiento.

### 4. Inteligencia Artificial Generativa Aplicada
* Arquitecturas **RAG (Retrieval-Augmented Generation)** conectadas a bases de datos estructuradas.
* Creación de un agente **Text-to-SQL** que permita a directores hacer preguntas en lenguaje natural y obtener consultas SQL validadas con gráficos automáticos.
